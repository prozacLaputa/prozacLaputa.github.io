# Prozac Laputa — Original Works

简体中文 | [English](README_EN.md) | [在线作品集](https://prozaclaputa.github.io/)

> 把自己的问题，做成可以使用的作品。

这是 [Prozac Laputa](https://github.com/prozacLaputa) 的个人原创作品集，集中展示独立设计、开发并公开的 AI 协作工具、macOS 应用与交互实验。

## 收录作品

- Vibe Canvas：随 Codex 对话生长的本地思考画板
- FlashThought：macOS 闪念捕捉器
- 问筊：潮汕跋杯 3D 浏览器体验
- CoMind 驾驶舱：连接 Codex 会话与已有笔记的原生 Mac 工作台（实验版）
- 口袋观测站：本地兴趣支出与购买预算预演
- 起身岛：Mac 顶部的喝水与起身提醒
- Free3 Mapper：Free3 的 macOS 独立映射工具
- 微光：StackChan 任务接力、猫系互动、专注、音乐与可选 AirPods 语音
- Decision UI for Codex：原生可点击决策 Skill
- Codex Usage HUD：Codex 桌面端额度悬浮标签
- 快捷启动：macOS 菜单栏快捷启动器

## 本地运行

```sh
npm ci
npm run dev
```

## 验证

```sh
npm test
```

推送到 `main` 后，GitHub Actions 会构建静态产物并部署到 GitHub Pages。
